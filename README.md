# Vincula | Red de Talento Universitario

Plataforma de vinculación laboral, empleabilidad y seguimiento de egresados para las Unidades Tecnológicas de Santander (UTS).

## 🚀 Módulos Principales

- **Portal del Egresado**: Exploración de vacantes exclusivas, postulaciones inteligentes, seguimiento de candidaturas y gestión de perfil laboral.
- **Portal Institucional (Asesor IES)**:
  - Validación de egresados y títulos académicos.
  - Seguimiento laboral 360° e inserción productiva (HU-27).
  - Estadísticas y analíticas de colocación, salarios y pertinencia curricular (HU-26).
  - Observatorio de competencias y mercado laboral (HU-28).
  - Gestión de convenios y empresas empleadoras (HU-25).
- **Backend Modular**: Arquitectura limpia con servicios, repositorios y modelos para la gestión de datos laborales.

## 🛠️ Tecnologías

- **Frontend**: React 18, Vite 8, TailwindCSS 4, Bootstrap 5, Boxicons, Plus Jakarta Sans & Inter.
- **Backend**: Python, FastAPI / Arquitectura modular.
